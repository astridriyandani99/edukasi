📄 Panduan Sinkronisasi Google Sheets

Agar setiap pengunjung yang mengakses leaflet otomatis tercatat ke spreadsheet rumah sakit Anda secara online, ikuti langkah berikut (hanya 1 menit):

  1. Buka Google Spreadsheet baru di Google Drive Anda.
  2. Klik menu Ekstensi (Extensions) → Apps Script.
  3. Hapus semua isi editor, lalu salin dan tempel kode skrip di bawah ini:
// Salin isi dari file: google-apps-script-template.js
  1. Klik Simpan (Save 💾).
  2. Klik tombol biru Terapkan (Deploy) → Penerapan baru (New deployment).
  3. Pilih jenis Aplikasi Web (Web app).
  4. Atur "Akses: Siapa saja (Anyone)" → klik Terapkan.
  5. Salin URL Aplikasi Web yang dihasilkan (berawalan https://script.google.com/macros/s/...).
  6. Buka file js/config.js di proyek ini dan tempel di baris TRACKER_WEBHOOK_URL: "URL_ANDA".
